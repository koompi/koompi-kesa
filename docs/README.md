## Everything else

The remaining files in this directory are working material rather than
documentation: conformance matrices, JSON contracts and schemas, evidence
bundles, program governance and audit snapshots. They are kept because tests and
release gates read them, and they are written for whoever is running that gate,
not for someone using KESA.

- `contracts/`, `schema/`, `wit/` — machine-readable contracts the test suites validate against.
- `evidence/` — recorded run artifacts referenced by closeout gates.
- `planning/` — architecture decision records and port-planning notes.
- `security/` — security workstream material.
- `extension-*.json`, `dropin-*.json`, `franken-node-*.json` — inventories and differentials generated by tooling.
